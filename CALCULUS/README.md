# 📘 Day 7 – Calculus & Optimization

Today, I completed the Mathematics Foundation for Machine Learning by learning the core concepts of calculus and optimization that enable machine learning models to learn from data.

## 📚 Topics Covered

### 🔹 Derivatives

* Learned that a derivative measures how quickly a quantity changes.
* Understood its role in measuring how model error changes with respect to parameters.
* Calculated derivatives using SymPy.

### 🔹 Partial Derivatives

* Learned that partial derivatives measure the effect of changing one variable while keeping others constant.
* Explored their importance in optimizing models with multiple parameters.

### 🔹 Chain Rule

* Understood how changes propagate through multiple functions.
* Learned that the chain rule is the mathematical foundation of backpropagation in neural networks.

### 🔹 Gradient

* Learned that the gradient points in the direction of the steepest increase of a function.
* Understood that optimization algorithms move in the opposite direction to minimize loss.

### 🔹 Gradient Descent

* Learned how Gradient Descent iteratively updates model parameters to minimize the loss function.
* Implemented a simple Gradient Descent algorithm to minimize (f(x) = x^2).

### 🔹 Stochastic Gradient Descent (SGD)

* Learned that SGD updates model parameters using one training example at a time.
* Understood its advantages in speed and scalability.

### 🔹 Mini-Batch Gradient Descent

* Learned that Mini-Batch Gradient Descent updates parameters using small batches of training data.
* Understood why it is the most commonly used optimization technique in deep learning.

### 🔹 Learning Rate

* Learned that the learning rate controls the size of each optimization step.
* Explored how choosing an appropriate learning rate affects convergence.

### 🔹 Convex vs Non-Convex Optimization

* Learned the difference between convex and non-convex functions.
* Understood why optimization is more challenging for non-convex loss functions commonly found in deep learning.

## 🎯 Key Takeaways

* Derivatives measure how quantities change.
* Partial derivatives optimize functions with multiple variables.
* The chain rule enables backpropagation in deep learning.
* Gradients indicate the direction of steepest increase.
* Gradient Descent minimizes loss by moving opposite the gradient.
* Learning rate controls optimization speed and stability.
* SGD and Mini-Batch Gradient Descent improve training efficiency.
* Convex optimization has one global minimum, while non-convex optimization may contain many local minima.
