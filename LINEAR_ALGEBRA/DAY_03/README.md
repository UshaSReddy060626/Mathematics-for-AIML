# 📘 Day 3 – Linear Algebra III

Today, I continued my Machine Learning Mathematics journey by learning advanced Linear Algebra concepts that are widely used in Machine Learning, Data Science, and Deep Learning.

## 📚 Topics Covered

### 🔹 Eigenvalues & Eigenvectors

* Learned that an eigenvector is a special direction that remains unchanged after a matrix transformation.
* Understood that an eigenvalue represents how much the eigenvector is stretched or shrunk.
* Explored their importance in dimensionality reduction and pattern recognition.

### 🔹 Principal Component Analysis (PCA)

* Learned the intuition behind PCA as a dimensionality reduction technique.
* Understood how PCA reduces the number of features while preserving most of the important information.
* Implemented PCA using Scikit-learn.

### 🔹 Singular Value Decomposition (SVD)

* Learned the intuition behind decomposing a large matrix into three simpler matrices.
* Explored how SVD is used in recommendation systems, image compression, search engines, and natural language processing.

### 🔹 Euclidean Distance

* Learned that Euclidean Distance measures the shortest straight-line distance between two points.
* Calculated Euclidean Distance using `np.linalg.norm()`.

### 🔹 Manhattan Distance

* Learned that Manhattan Distance measures the distance traveled along grid-like paths.
* Calculated Manhattan Distance using `np.sum(np.abs(A - B))`.

### 🔹 L1 & L2 Norms

* Learned that the L1 Norm is the sum of absolute values and is commonly used for feature selection.
* Learned that the L2 Norm represents the length (magnitude) of a vector and is widely used in machine learning regularization.

## 🎯 Key Takeaways

* Eigenvectors identify important directions in data.
* Eigenvalues measure the amount of stretching or shrinking along those directions.
* PCA reduces dimensionality while preserving useful information.
* SVD simplifies complex matrices for efficient computation.
* Euclidean and Manhattan distances measure similarity in different ways.
* L1 and L2 norms are essential tools for measuring vectors and regularizing machine learning models.
