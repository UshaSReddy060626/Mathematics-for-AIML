# 📘 Day 2 – Linear Algebra II

Today, I continued my Machine Learning Mathematics journey by learning **Matrices**, one of the most fundamental concepts in Linear Algebra and the backbone of Machine Learning, Deep Learning, and Artificial Intelligence.

## 📚 Topics Covered

### 🔹 Matrices

* Learned that a matrix is a rectangular arrangement of numbers in rows and columns.
* Understood how matrices are used to represent datasets, images, and neural network weights.

### 🔹 Matrix Operations

Practiced:

* Matrix Addition
* Matrix Subtraction
* Scalar Multiplication

### 🔹 Matrix Multiplication

* Learned the row × column multiplication rule.
* Understood why matrix multiplication is different from element-wise multiplication.
* Implemented matrix multiplication using:

  * `@`
  * `np.matmul()`

### 🔹 Identity Matrix

* Learned that the identity matrix is the matrix equivalent of the number **1**.
* Created identity matrices using:

  * `np.eye()`

### 🔹 Transpose

* Learned how transpose converts rows into columns.
* Implemented transpose using:

  * `.T`

### 🔹 Inverse Matrix

* Learned that the inverse of a matrix is similar to the reciprocal of a number.
* Understood the property:

  * `A × A⁻¹ = I`
* Computed inverses using:

  * `np.linalg.inv()`

### 🔹 Determinant

* Learned that the determinant indicates whether a matrix is invertible.
* Calculated determinants using:

  * `np.linalg.det()`
* Understood:

  * `det(A) = 0` → No inverse
  * `det(A) ≠ 0` → Inverse exists

## 🎯 Key Takeaways

* A matrix is a collection of numbers arranged in rows and columns.
* Matrix multiplication follows the row × column rule.
* The identity matrix behaves like the number 1 for matrices.
* Transpose swaps rows and columns.
* The determinant tells whether an inverse exists.
* Matrices are everywhere in modern AI, from images to neural network computations.
