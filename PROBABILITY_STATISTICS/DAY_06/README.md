# 📘 Day 6 – Statistics III

Today, I continued my Machine Learning Mathematics journey by learning advanced statistical concepts used to analyze relationships between variables, estimate population characteristics, and evaluate claims using data.

## 📚 Topics Covered

### 🔹 Covariance

* Learned that covariance measures whether two variables move together.
* Understood the difference between positive, negative, and zero covariance.
* Calculated covariance using `np.cov()`.

### 🔹 Correlation

* Learned that correlation measures both the direction and strength of a relationship.
* Understood that correlation values range from **-1 to +1**.
* Calculated correlation using `np.corrcoef()`.

### 🔹 Central Limit Theorem (CLT)

* Learned that the distribution of sample means tends to become approximately normal when repeatedly sampling from a population, provided the sample size is sufficiently large and common assumptions hold.
* Understood why CLT is fundamental for statistical inference and data analysis.

### 🔹 Confidence Interval

* Learned that a confidence interval provides a likely range for an unknown population parameter.
* Calculated a 95% confidence interval using SciPy.

### 🔹 Hypothesis Testing

* Learned the concepts of the Null Hypothesis (H₀) and Alternative Hypothesis (H₁).
* Understood how statistical tests help evaluate claims using sample data.

### 🔹 p-value

* Learned that the p-value measures how unusual the observed data would be if the null hypothesis were true.
* Understood the common interpretation of the 0.05 significance level and its limitations.

## 🎯 Key Takeaways

* Correlation measures both the strength and direction of relationships.
* The Central Limit Theorem enables reliable inference from samples.
* Confidence intervals express uncertainty around estimates.
* Hypothesis testing provides a framework for evaluating claims.
